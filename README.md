# Ravali Salakala · Portfolio

Personal portfolio for Ravali Salakala, Senior Frontend Engineer.

Built with Next.js 15, React 19, Tailwind CSS v4 and Framer Motion. The hero features an
interactive painted avatar whose eyes follow your cursor, blinks, blushes when you come
close, winks when clicked and glances down as you scroll.

```bash
npm install
npm run dev
```

Content lives in `src/data/resume.ts`.
